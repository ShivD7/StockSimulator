# Stock Simulator

A Java Swing app for paper trading.

* Creates local accounts and saves user data.
* Looks up stock prices through Alpha Vantage.
* Offers US, TSX, London, and Shanghai exchange selections.
* Shows price data, daily highs, and daily lows.
* Plots stock price history.
* Buys and sells shares with a simulated cash balance.
* Tracks holdings, purchase prices, and portfolio value.
* Shows portfolio allocation in a pie chart.
* Compares portfolio values with selected users.
* Finds news articles for US stock tickers and opens their links.
* Includes an OpenAI chat assistant.

Market data and the chat assistant need working API access. No real trades are placed.
